# ISUCON2026 ちゃれんじろぐの記事追加

## 対象ファイル

`src/content/blog/20260831-isucon2026.md` の frontmatter にある `isuconEntries` のみを編集する。

本文、ページタイトル、タグ、メンバー紹介、その他のファイルは変更しない。

## 登録できる項目

1件の記事につき、次の3項目だけを登録する。

```yaml
- title: '記事タイトル'
  member: 'とぴ'
  link: 'https://example.com/article'
```

- `title`: 空ではない記事タイトル
- `member`: `とぴ`、`sora`、`wabi` のいずれか
- `link`: `https://` または `http://` で始まる記事URL

これ以外の項目は追加しない。メンバー名の表記を勝手に変更・追加しない。

## 手順

1. 対象ファイルを読む
2. タイトル、メンバー、リンクがすべて指定されていることを確認する
3. 同じリンクが未登録であることを確認する
4. `isuconEntries` の先頭に新しい記事を追加する
5. ビルドまたはコンテンツ検証を実行する
6. `main` ブランチへ直接反映せず、Pull Requestとして変更を提案する

情報が不足している場合や、メンバーが3名以外の場合は編集せず、ユーザーに確認する。
